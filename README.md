# Haverbex — company site

The built static company page of Haverbex, served at the root of this GitHub Pages user site.

*   EG2-KO Reader (product page): https://topabaem05.github.io/eg2-ko-reader-demo/eg2-ko-reader/
*   Model: https://huggingface.co/Haverbex/eg2-ko-reader
*   Demo Space: https://huggingface.co/spaces/topabaem/eg2-ko-reader-demo

This repository holds only the built static files (HTML, JavaScript, CSS and fonts), made
with Vite, React, Tailwind, shadcn/ui, GSAP and heerich (voxels, MIT). The fonts are
Pretendard and Geist Mono (SIL Open Font License 1.1).

Contact: guritopabaem@gmail.com (commercial use of the model by organizations: subject
starting with `[Commercial]`).
